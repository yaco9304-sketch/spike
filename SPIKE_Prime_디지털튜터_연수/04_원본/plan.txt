# LEGO SPIKE Prime 디지털튜터 연수자료 제작 계획 및 화면 수집 매핑안
## 세종 권역 교육생 요구사항 + 신규/전·현직 강의계획서 반영본


---


# 0. 문서 목적


본 문서는 LEGO Education SPIKE Prime을 활용한 디지털튜터 연수자료 제작을 위한 통합 기획서이다.


다음 두 작업을 동시에 정의한다.


1. 신규 과정과 전·현직 과정의 연수자료 제작 방향
2. 코딩 에이전트가 실제 SPIKE App/Web App에서 수집해야 할 화면과 각 화면의 사용처


※ 미션맵은 본 제작 범위에서 제외한다.


---


# 1. 세종 권역 교육생 요구사항


세종 권역 교육생 요구는 다음 네 가지로 정리한다.


1. 로봇 교구의 기본 활용 방법
2. 바로 수업에 적용할 수 있는 수업 예제
3. 연결 오류 등 실제 학교 현장에서 자주 발생하는 문제 대응
4. 중학생 수준까지 확장 가능한 내용


또한 LEGO SPIKE Prime이 직접 언급되었으므로 본 연수의 중심 교구는 LEGO Education SPIKE Prime으로 한다.


과정별 요구사항은 다음과 같이 차별화한다.


## 신규 과정


> **기본 조작 + 바로 수업에 적용할 수 있는 예제 중심**


핵심:
- 처음 사용하는 사람도 따라갈 수 있어야 함
- 조립과 연결을 직접 경험
- 기본 블록코딩
- 센서와 모터 활용
- 학생들과 바로 해볼 수 있는 활동
- 기본적인 연결 및 작동 오류 대응


## 전·현직 과정


> **학년별 수업 적용 + 수업 지원 관점의 심화 내용 중심**


핵심:
- 기본 사용법 반복 최소화
- 같은 SPIKE 활동을 학년별로 어떻게 확장하는지 제시
- 초등 → 중학교 수준 연결
- 센서 데이터 활용
- 변수·조건·반복·함수
- Python
- 복합 제어
- 연결·펌웨어·센서·코드 오류 대응
- 학생 문제해결을 지원하는 튜터링 방법

# 3. 전체 연수의 공통 개념


SPIKE Prime을 통해 반복적으로 다음 구조를 이해하도록 한다.


```text
입력
↓
센서 데이터
↓
프로그램의 판단
↓
출력
```


예:


```text
거리센서
↓
17cm
↓
20cm보다 가까운가?
↓
모터 정지
```


연수 전체의 핵심 피지컬 컴퓨팅 개념은 다음과 같다.


> **입력 → 데이터 → 판단 → 출력 → 테스트 → 수정**

# 4. 신규 과정 제작 방향


# 4-1. 신규 과정 목표


> **SPIKE Prime을 처음 받아도 연결하고 기본 코딩을 해서 학생들과 1차시 수업을 운영·지원할 수 있다.**


---


# 4-2. 신규 1차시
## SPIKE Prime 처음 시작하기 + Driving Base


### 주요 흐름


1. SPIKE Prime 구성품 확인
2. Hub·모터·센서·포트 이해
3. 노트북/태블릿에서 SPIKE 실행
4. Hub 연결
5. Driving Base 직접 조립
6. 기본 블록코딩
7. 직진
8. 후진
9. 좌회전
10. 우회전
11. 정지
12. 간단한 주행 활동


### 1차시 도달점


> **조립 → 연결 → 코딩 → 기본 주행 성공**


### 신규 과정에서 중요한 점


Driving Base를 미리 완성해서 제공하지 않는다.


직접 조립하면서 다음을 이해하도록 한다.


- Hub 방향
- 모터 방향
- 포트
- 좌우 바퀴
- 케이블
- 구동 구조


---


# 4-3. 신규 2차시
## 센서로 판단하는 로봇 만들기


### 사용할 기능


- 힘센서
- 거리센서
- 컬러센서
- Hub 자이로/모션센서
- 조건문
- 반복문


### 활동 구조


센서를 기능별로 설명하는 것에 그치지 않는다.


```text
센서 연결
↓
센서값 확인
↓
조건 만들기
↓
모터 동작
```


### 예시


#### 힘센서


```text
힘센서를 누르면
→ 출발
```


#### 거리센서


```text
거리 < 20cm
→ 정지
```


#### 컬러센서


```text
검은색 감지
→ 정지
```


#### 자이로


```text
목표 각도 90°
→ 회전
```

# 4-4. 신규 과정의 '바로 수업에 적용 가능한 예제'


신규 과정에서는 작품 제작보다 **학교에서 1차시 활동으로 바로 활용할 수 있는 수준**을 우선한다.


예제 후보:


### 예제 A. 버튼으로 출발하는 로봇


```text
힘센서를 누르면 출발한다.
```


활용 개념:
- 입력과 출력
- 이벤트
- 모터


---


### 예제 B. 장애물 앞에서 멈추는 로봇


```text
거리센서 값이 20cm보다 작으면 멈춘다.
```


활용 개념:
- 센서값
- 조건문
- 반복


---


### 예제 C. 색을 인식하는 로봇


```text
검은색을 발견하면 정지한다.
```


활용 개념:
- 컬러센서
- 조건
- 환경에 반응하는 프로그램


---


### 예제 D. 정확히 방향을 바꾸는 로봇


```text
자이로센서를 이용하여 90도 회전한다.
```


활용 개념:
- 센서값
- 방향
- 피드백

> **SPIKE Prime 활동을 학년 수준에 맞게 변형하고, 초등에서 중학교까지 센서·데이터·Python 수준으로 확장하며, 학생의 문제해결과 현장 오류 대응을 지원할 수 있다.**

## 초등 3~4학년 수준


```text

```


또는



```text

        이동
```

핵심:
- 조건
- 반복
- 센서값 비교
- 문제해결

## 중학교 수준


```text
거리값에 따라
모터 속도를 계산하여 조절
```


예:


```text
속도 = 거리 × 비율
```


핵심:
- 변수
- 데이터
- 수식
- 알고리즘 개선
- 제어

- 변수
- 조건문
- 반복문
- 함수
- 센서값
- 데이터에 따른 출력 조절


### 블록과 Python 비교


예:


#### 블록


```text
계속 반복
    만약 거리 < 20
        정지
```


#### Python


실제 SPIKE Python API를 확인하여 같은 알고리즘으로 표현한다.


중요:


> 일반 Python 예제를 임의로 SPIKE API처럼 작성하지 않는다.


코딩 에이전트가 실제 SPIKE App의 Python 환경, 자동완성, 공식 예제를 확인하여 유효한 코드만 수집한다.

# 5-7. 라인트레이싱 수준 확장


## 기본


```text
검은색
→ 왼쪽


흰색
→ 오른쪽
```


---


## 심화


```text
오차 = 현재 반사광값 - 기준값
```


```text
조향값 = 오차 × K
```


이를 통해 간단한 P 제어 개념까지 연결한다.

# 6. 디지털튜터의 수업 지원 관점


전·현직 과정에서는 특히 다음을 강조한다.


학생이 말한다.


> "선생님, 안 돼요."


튜터가 바로 코드를 고쳐주는 것이 아니다.


## 지원 흐름


```text
1. 지금 어떤 값이 들어오고 있나요?
2. 센서가 제대로 연결되어 있나요?
3. 어느 조건에서 동작해야 하나요?
4. 실제 조건이 맞나요?
5. 모터만 따로 실행하면 움직이나요?
6. 하나씩 다시 연결해 볼까요?
```


목표:


> **완성 코드 제공이 아니라 학생의 디버깅 과정 지원**
